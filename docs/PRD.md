## 1. EXECUTIVE SUMMARY

**Продукт:** AI-Native MarketplaceTech Platform — аналог Easy Commerce (easycomm.ru)
**Кодовое название:** MarketFlow

MarketFlow — это AI-Native платформа полного цикла для управления продажами на российских маркетплейсах (Wildberries, Ozon, Яндекс Маркет, MegaMarket), объединяющая:
- **CAT-аналог** (Commerce Analytics Tool) — real-time аналитика с AI-рекомендациями
- **E-commerce Tool** — единое окно управления всеми площадками
- **AI-агент** — автономное управление ставками, контентом, отзывами
- **Managed Services Layer** — full-service для enterprise-брендов (не опциональный — ключевой)

**Уникальная позиция (Variant C — Enterprise AI-Native):** Первый AI-Native игрок на российском рынке с **Agentic Commerce Optimization (ACO)** — AI-агент выполняет задачи **вживую на демо**, что невозможно у конкурентов. AHA момент: клиент говорит задачу — агент решает её за 10 минут на встрече.

**Стратегия GTM:** Thought Leadership → Account-Based Sales → POC 90 дней → Platform License + Success Fee (% от прироста GMV). Минимальный чек: 500к₽/мес.

**CJM Variant C Journey:** Awareness (research content) → Demo AHA → Integration (ERP/1С) → Contract → Continuous Learning → Ecosystem Expansion (B2B2B).

## 2. PROBLEM STATEMENT

### Ситуация
Российский e-commerce рынок достиг 5.3 трлн₽ в 2025. 1.26 млн продавцов работают на WB/Ozon/YM/MM.

### Проблема
- **Комиссии выросли** с 15-20% до 30%+ (2025)
- **ДРР рекламы**: 18-30% оборота (было 8%)
- **Ручной труд**: аналитика занимает 15-20 ч/неделю у каждого менеджера
- **Разрозненность**: 4+ разных кабинета для управления одним магазином
- **Экспертный дефицит**: 1.26М продавцов при дефиците квалифицированных специалистов

### Корневая причина
Маркетплейсы стали медиаплатформами с платным трафиком, но большинство продавцов управляют ими как «магазинами» вручную — без данных, без автоматизации, без экспертизы.

### Решение
AI-агент как «виртуальный менеджер маркетплейса» — делает всё то, что делает команда из 3-5 человек, за 10% цены.

## 3. TARGET USERS (CJM Variant C — Enterprise First)

> **Фокус Variant C:** Primary persona — Дмитрий (Enterprise). Анна и Максим — secondary (upsell от enterprise-рефералов, B2B2B эффект).

### Persona 1 (PRIMARY): Дмитрий, E-com Director Enterprise ⭐
- **Компания:** Федеральный ритейлер / крупный бренд, оборот 5Б₽+/год, маркетплейсы = 35% выручки
- **Боль:** «Маркетплейсы 35% выручки, но внутренняя команда не справляется. CEO ставит KPI +40% GMV»
- **Job:** Нужен стратегический технопартнёр с гарантиями результата и автономными AI-агентами
- **Trigger:** Квартальный board review — e-com отстаёт от плана на 15%+
- **AHA Moment:** На демо AI-агент за 10 минут анализирует их реальные карточки и показывает конкретный прирост
- **Готов платить:** 500к-2М₽/мес (Platform License + Success Fee % от GMV)
- **Цикл сделки:** 1-3 месяца → POC 90 дней → годовой контракт

### Persona 2 (SECONDARY): Максим, Brand Manager
- **Компания:** Бренд FMCG, оборот 300М₽/год на маркетплейсах
- **Боль:** «Не понимаю почему продажи упали на 20% — нет данных»
- **Job:** Data-driven отчёт + AI-рекомендации без найма специалистов
- **Trigger:** Дмитрий (enterprise-клиент) рекомендует MarketFlow своим поставщикам — B2B2B
- **Готов платить:** 150-400к₽/мес за managed services

### Persona 3 (SECONDARY via B2B2B): Анна, Seller
- **Бизнес:** Реселлер на WB+Ozon, оборот 8М₽/мес
- **Приходит через:** Дистрибьютор / поставщик enterprise-клиента рекомендует платформу
- **Готов платить:** 10-25к₽/мес за SaaS (upsell путь, не GTM-фокус)
