## A. GROWTH LOOP

### Primary Loop: PLG Data Flywheel

```
[Бесплатный SaaS trial]
      ↓
[Подключение API маркетплейса]
      ↓
[AI находит точки роста → "Вау" момент]
      ↓
[Платная подписка + Реферал в Telegram]
      ↓
[Больше данных → AI умнее → Лучшие результаты]
      ↓
[Кейс → Публичное признание → Органический трафик]
      ↓
[Новые пользователи → (loop)]
```

**Data Moat:** Каждый новый клиент добавляет данные в модель → AI становится умнее → следующий клиент получает лучший результат → flywheel ускоряется. Sourced: [NFX: AI-First Marketplace](https://www.nfx.com/post/ai-first-marketplace)

## C. RETENTION STRATEGY

### Hook Model (Nir Eyal)

| Этап | Механика |
|------|----------|
| **Trigger** | Утренний Telegram-дайджест: «3 задачи для роста сегодня» |
| **Action** | Клик → проверка метрик в дашборде |
| **Variable Reward** | Продажи выросли на X% → эндорфин. Иногда "бонус-сигнал": новый конкурент или тренд |
| **Investment** | Клиент настраивает правила, добавляет SKU, обучает AI предпочтениям |

**Retention Metrics Targets:**
- D7 Retention (SaaS): >60%
- D30 Retention: >40%
- 6-month Retention (Managed): >90%
