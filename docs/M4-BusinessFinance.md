**Ключевые риски:**
1. Wildberries/Ozon закрывают API → потеря SaaS-ценности (mitigation: агентская экспертиза + управление через UI)
2. Длинный цикл managed-продаж (2-4 мес) при высоком CAC → cash flow проблема (mitigation: SaaS-первый подход)
3. Конкуренция с MPSTATS в PLG → ценовые войны (mitigation: AI-дифференциация)
