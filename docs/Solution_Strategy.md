# Solution Strategy: MarketFlow
**Дата:** 2026-03-18 | **Метод:** First Principles + TRIZ + Game Theory

---

## PROBLEM STATEMENT (SCQA)

**Situation:** Российский e-commerce рынок достиг 5.3 трлн₽ в 2025. 1.26 млн продавцов работают на WB/Ozon.

**Complication:** Комиссии выросли до 30%+, ДРР рекламы удвоился. Ручное управление продажами стало нерентабельным, но квалифицированных специалистов катастрофически не хватает.

**Question:** Как позволить любому продавцу управлять продажами на маркетплейсах с уровнем эффективности профессиональной команды, без найма этой команды?

**Answer:** AI-агент как «виртуальный менеджер маркетплейса» — автономный, обучаемый, дешевле найма в 10×.

---

## FIRST PRINCIPLES ANALYSIS

**Что нужно клиенту фундаментально:**
1. Продавать больше товаров
2. Тратить меньше на рекламу
3. Тратить меньше времени на управление
4. Понимать почему продажи растут/падают

**Что НЕ нужно клиенту:**
- Инструмент для аналитики (это средство, не цель)
- Агентство (это тоже средство)
- Красивые дашборды без actionable insights

**Вывод First Principles:** Клиент хочет **рост GMV при снижении операционных затрат**. Всё остальное — производное.

---

## ROOT CAUSE ANALYSIS (5 WHYS)

**Проблема:** Бренды теряют деньги на маркетплейсах

1. **Почему?** → Реклама дорогая и неэффективная (ДРР 20-30%)
2. **Почему?** → Менеджеры управляют ставками вручную без данных о конкурентах
3. **Почему?** → Нет инструмента который видит данные конкурентов + автоматически оптимизирует ставки
4. **Почему?** → Маркетплейсы не дают эти данные бесплатно, нужен агрегатор
5. **Почему?** → **Root Cause:** Рынок инструментов для маркетплейсов в РФ разрознен: аналитика отдельно, управление отдельно, исполнение отдельно. Нет единого AI-агента.

## GAME THEORY ANALYSIS

### Ключевые игроки:

| Игрок | Мотивация | Реакция на наш выход |
|-------|-----------|---------------------|
| Easy Commerce | Защита #1 позиции | Запустит AI-фичу в CAT (80% вероятность) |
| MPSTATS | Рост подписчиков | Добавит managed услуги (50%) |
| WB/Ozon | Монетизация экосистемы | Запустит собственные tools (50%, 2-3 года) |
| Клиенты (бренды) | ROI | Переключатся при лучшем value prop |

### Nash Equilibrium:
Вход с **AI-differentiated позиционированием** (не конкурируя в аналитике с MPSTATS) → incumbents не реагируют немедленно → window of opportunity 12-18 месяцев.

## CONTRADICTIONS RESOLVED (TRIZ)

| Противоречие | TRIZ Принцип | Решение |
|--------------|-------------|---------|
| Хотим масштабировать сервис (рост команды) vs. сохранить маржу (не нанимать) | #10 Prior Action | AI-агент «готовит» всё заранее, люди только проверяют → 10× производительность |
| Хотим персонализацию (high-touch) vs. низкую цену (low-cost) | #1 Segmentation | Freemium SaaS для self-serve, managed для enterprise — разные слои одной платформы |
| Хотим быть лучше конкурентов (quality) vs. выйти быстро (speed) | #9 Prior Counteraction | MVP = только AI-рекомендации (не исполнение). Конкуренция пока не замечает. Потом запускаем агента. |
| API ограничения от WB vs. нужны данные конкурентов | #3 Local Quality | Комбинируем официальный API + публично доступные данные + партнёрские данные |

## SECOND-ORDER EFFECTS

| Если мы делаем X | First order | Second order | Third order |
|-----------------|-------------|--------------|-------------|
| Запускаем AI-автоматизацию ставок | Клиенты экономят ДРР | Easy Commerce запускает аналог | Рынок commoditizes → нужен следующий differentiator (платформа) |
| Строим Data Flywheel | Умнее AI → лучшие результаты | Больше клиентов → больше данных → ещё умнее | WB/Ozon хотят купить нас OR ограничивают API |
| Публикуем кейсы (×3 выручка за месяц) | Трафик и лиды | Конкуренты копируют подход | Стандарт индустрии — кейсы перестают работать, нужны другие метрики |

## RECOMMENDED APPROACH

### Стратегия: «AI-First Hybrid (A+B→C)»

**Фаза 1 (M1-M6): PLG SaaS Entry (Вариант B)**
- Freemium CAT-аналог для mid-market
- AI-рекомендации как core value
- Viral через Telegram-сообщество
- CAC < 10к₽ через PLG

**Фаза 2 (M7-M12): Managed Upsell (Вариант A)**
- Лучших SaaS-клиентов конвертируем в managed
- «Хочешь чтобы мы это сделали за тебя?»
- Managed = 10× revenue от SaaS

**Фаза 3 (M13-M24): Platform (Вариант C)**
- AI-агент для enterprise (ERP-интеграции)
- B2B2B: каждый enterprise приводит 3-5 SMB
- Agentic Commerce Optimization (ACO)
