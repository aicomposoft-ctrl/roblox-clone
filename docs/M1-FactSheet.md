### 1. Commerce Analytics Tool (CAT)
- Собственный аналитический инструмент
- Сбор данных по всем ключевым маркетплейсам
- Отслеживает: категории, конкурентов, цены, качество карточек, отзывы
- Десятки метрик в единой панели
- **Источник:** [easycomm.ru/cat](https://easycomm.ru/cat) | Confidence: 0.97

### 2. E-commerce Tool
- Единое окно для управления кампаниями на нескольких маркетплейсах
- Подключается по подписке «в два клика»
- Целевая аудитория: селлеры (не только бренды)
- **Источник:** [easycomm.ru](https://easycomm.ru/blog/tpost/dg0np9agy1-easy-commerce-zapustil-e-commerce-tool-i) | Confidence: 0.95

### 3. Managed Services (Full-Service Agency)
- **Аналитика:** ABC-анализ категорий, поиск точек роста, внутренний research кабинетов
- **Реклама:** внутренняя + внешний трафик, прогноз ROAS, баннеры, промо
- **Контент:** 360° фото/видео, rich-контент, описания карточек, SEO
- **SEO карточек:** управление ставками, оптимизация позиций, алгоритмы площадок
